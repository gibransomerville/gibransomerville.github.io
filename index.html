Personal utility · Gibran Somerville

Personal reporting, delivered to its owner.

pf-daily-mail is a private utility operated by Gibran Somerville. It emails generated personal-finance workbook reports from the owner’s Gmail account to that same account.

One owner. One recipient. Send-only Gmail access.

The utility requests Google’s gmail.send permission. It does not request permission to read existing email, delete messages, or manage the mailbox.

How it works

A scheduled job prepares a workbook and uses the Gmail API to send it as an attachment. Google authorization credentials are stored as secrets in Fly.io, where the sending job runs.

This website provides information about the utility. It has no sign-up form and does not provide public access to the app, reports, or account credentials.
