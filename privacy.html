Privacy Policy

Effective October 23, 2026. This policy describes the Gmail integration in pf-daily-mail, a personal utility operated by Gibran Somerville.

Information used and purpose

The utility uses the owner’s Gmail address, OAuth credentials, and the outgoing message and workbook attachment to deliver reports to the owner. It requests only https://www.googleapis.com/auth/gmail.send. It does not read existing email, contacts, or mailbox contents.

Storage and service providers

OAuth client credentials and the refresh token are stored as Fly.io secrets and supplied to the sending job. Access tokens are used in memory. Google processes and stores sent and received messages according to the owner’s Gmail settings. The private reporting system records delivery status and the Gmail message identifier. Generated reports and underlying reporting records are managed separately in the owner’s private finance system.

Google and Fly.io process the information needed to authorize and deliver mail. This Gmail integration does not sell Google user data, use it for advertising, or use it to train AI models. Google user data is not shared with unrelated third parties.

Retention and control

Credentials remain available until the owner revokes access or removes the Fly secrets. The owner can revoke access through Google Account connections, stop the job, remove its stored credentials and delivery records, and delete messages from Gmail. Deleting the credentials stops future authorized delivery; it does not remove messages already delivered.

Google API limited use

pf-daily-mail’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

This website

These static information pages use no application cookies, analytics scripts, or submission forms. GitHub Pages hosts the site and may process standard web request information under GitHub’s Privacy Statement.

Questions or removal requests

Contact gibransomerville@gmail.com. Material changes to these practices will be reflected on this page with an updated effective date.
